# 서버 테스트

- 통합 테스트는 Testcontainers MySQL로 돌린다. H2로 대체하지 않는다(조건부 UPDATE, 유니크 제약 동작을 실제 DB에서 확인해야 한다).
- 인가 매트릭스: 각 API를 비로그인 / 로그인(타인) / 스트리머·작성자 세 주체로 호출해 허용·거절(401/403)을 검증한다. 기대값은 `.claude/rules/auth.md`의 접근 규칙 표를 따른다.
- 상태 관리: 방송 상태 전이(정상·비정상 종료 경쟁 포함), 송출 토큰 1회 소비·만료·path 불일치, 후원 확정 멱등(같은 승인 통지 반복)을 테스트한다.
- `ArchitectureTest`(ArchUnit)는 `app` 모듈에 있다. 구조를 바꾼 뒤에는 이 테스트를 돌린다.
- 프론트와 미디어(WebRTC) E2E는 자동화하지 않는다. 대신 README의 기능 확인 절차를 갱신한다.
