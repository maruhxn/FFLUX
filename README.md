# FFLUX: 실시간 방송 플랫폼 개발

- 서비스 주소: 실제 접속 가능한 URL
- 테스트 계정: 평가용 계정 정보 또는 테스트 계정으로 바로 로그인하는 기능 및 이용 방법
- 실행 방법: 실행 환경과 환경변수 예시
- 기능 확인: PC 및 모바일 방송 송출, 시청, 종료 방법과 지원 환경

서비스 접속이나 테스트 로그인이 불가능한 경우 평가에 반영될 수 있습니다.

시연 영상 링크는 선택 사항입니다. README는 심사자가 기능을 쉽게 확인할 수 있도록 명확하게 작성해 주세요.

## 지원 환경

| 기능 | 환경 |
|---|---|
| PC 송출 | Chrome/Edge 최신. 화면 소리는 Windows에서 시스템 소리, macOS에서는 탭 소리만 |
| 모바일 송출 | Android Chrome, iOS Safari. 카메라와 마이크로 송출하고, 송출 중 화면이 꺼지지 않게 한다(Wake Lock). 다른 앱으로 전환하거나 화면을 끄면 송출이 끊겨 방송이 종료된다 |
| 시청 | 최신 브라우저 전부. WebRTC(WHEP)로 연결하고, 안 되면 HLS로 자동 전환한다. Safari(iOS 포함)는 브라우저 기본 HLS, 그 밖의 브라우저는 hls.js로 재생한다 |

## 기능 확인 절차

### 시청

1. 스트리머 계정으로 방송을 등록하고 상세 화면의 "방송 시작"으로 송출한다. PC는 화면 공유, 휴대폰(터치 기기)은 카메라로 송출 화면이 열린다.
2. 다른 브라우저나 휴대폰에서 로그인 없이 메인 화면의 LIVE 방송을 연다. 플레이어가 바로 재생된다(처음에는 소리가 꺼져 있다).
3. 플레이어 왼쪽 아래 표시로 연결 방식(WebRTC/HLS)을 확인하고, "소리 켜기"와 "전체 화면"을 눌러 본다.
4. 스트리머가 "방송 종료"를 누르면 몇 초 안에 시청 화면이 "종료된 방송"으로 바뀐다.
